# Arkaya Global Services — Static Website

A responsive, static website for an independent router and networking assistance provider.

## Files
- `index.html` — landing page and service overview
- `terms.html` — terms and conditions draft
- `privacy.html` — privacy policy draft
- `refunds.html` — refund and cancellation policy draft
- `contact.html` — contact page
- `assets/styles.css` — responsive styling
- `assets/main.js` — small client-side enhancement

## Important before publishing
1. Confirm the real service deliverables and whether US$399.99 is an appropriate, accurate one-time fee.
2. Replace draft policy wording with the actual policies your business can honor and get legal review as needed.
3. The site currently does not process payments. The primary button opens an email request; it does not create an order or charge a customer.
4. Replace the email if your business contact changes.
5. Do not advertise as Apple Support or imply Apple, an ISP, or a router manufacturer sent the visitor a message. This is an independent service.
6. Do not claim a guaranteed fix unless that guarantee is real and documented.

## Preview locally
Open `index.html` in a modern browser. No build step is required.

## Hosting
**Recommended: Vercel static deployment.** Import the project folder/repository into Vercel; no build command is needed for this plain static site. You can also deploy the static files to another host that permits commercial websites. GitHub Pages' published policy says it is not intended for hosting online businesses primarily directed at commercial transactions, so do not use GitHub Pages for this commercial checkout/service site.

## Payments
No payment integration is included because the provider/account has not been selected. Do not collect card details in a custom HTML form. When ready, integrate a reputable hosted checkout with server-side verification and clear order confirmation, cancellation, and refund terms.
